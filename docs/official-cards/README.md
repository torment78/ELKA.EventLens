## GitHub Social Preview

Use `docs/assets/github-social-preview.jpg` for GitHub's social preview. It is 1280 x 640, matching [GitHub's recommended dimensions](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview). The vertical JPEG is also under 1 MB, but its portrait shape does not match GitHub's recommended wide frame.

In the repository's **Settings > General > Social preview**, choose **Edit > Upload an image**. The image is supplied here; storing it in the repo does not automatically change that setting.

## Stored Copies

The original PNGs, smaller JPEGs, and ZIP are version-controlled in this repository and backed up on GitHub. The ZIP contains both orientations, the app icon, installer branding, generation prompts, and documentation. Files retain their repository folder paths inside the ZIP. Extract it and open `docs/official-cards/README.md` to browse the images.

Run `scripts/Prepare-Branding.ps1` from the repository to regenerate the smaller images and ZIP. The ZIP includes artwork only, with no application settings, captured events, or browser profiles.

Both cards use the ELKA tools-family circuit traces, EventLens mint/teal/amber palette, and approved event-log/lens icon.
