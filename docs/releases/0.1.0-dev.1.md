# ELKA EventLens 0.1.0-dev.1

**Development preview for testing. Not a stable release.**

## Included

- Recent and live Windows events in expandable cards, with local explanations, technical details, and raw XML.
- Integrated search tabs, selectable search engine, and ChatGPT/Claude/Copilot browser sign-in and prompt assistance.
- Custom corner notifications, notification history, and a themed system tray menu.
- Dark app/browser options, customizable appearance, and pixel-based scrolling.
- ELKA tools-family trace artwork, dimensional icon, and a dark branded installer.

## Downloads

- `ELKA_EventLens_Setup_0.1.0-dev.1.exe`: normal installation under `Program Files\Elka Software\ELKA EventLens`.
- `ELKA_EventLens_Portable_0.1.0-dev.1.zip`: extract the complete `ElkaEventLensPort` folder and run `ELKA.EventLens.App.exe`.
- `SHA256SUMS-0.1.0-dev.1.txt`: checksums for both packages.

Windows 10/11 x64; .NET is bundled. Setup installs Microsoft WebView2 if missing (internet required). Portable users need the WebView2 Runtime installed on the computer. The EXE and installer are unsigned development builds.

Minimize and close hide to the tray. Use the tray menu's **Exit** command to quit.

## Known Limitations

- AI auto-send and website darkening are best-effort and depend on third-party websites. Review event text before sending it to an external service; it may include machine names, paths, or other sensitive details.
- Browser sign-in sessions persist locally but may not transfer across Windows accounts or computers.
- Security log access may require administrator permissions. Other logs continue working if access is denied.
- Event explanations suggest possible causes; they are not a diagnosis or a guarantee that a proposed fix applies.
- Automatic browser-cache cleanup and start-with-Windows support are not included yet.

## Validation

The development build passes 50 Windows UI/browser checks using synthetic event data and local browser fixtures. These cover wrapping, resizing, scroll increments, settings, search URL restrictions, browser darkening, tab retention, and AI send-once behavior.

The installer also passed an isolated current-user install/uninstall smoke test on a computer with WebView2 already installed. The portable archive was checked for required runtime files and the absence of private history, logs, and browser profiles. The missing-WebView2 download/install path and graphical wizard layout still need testing on another Windows computer.
