# ELKA EventLens 0.1.0-dev.2

**Development preview for testing. Not a stable release.**

This increments the previous preview from `0.1.0-dev.1` to `0.1.0-dev.2`.

## Changes

- New installations default to `C:\Program Files\ElkaSoft\ELKA EventLens` (using the Windows Program Files location).
- Settings and history now use `%AppData%\ElkaSoft\ELKA EventLens\Saves`.
- Logs and browser storage now use `%LocalAppData%\ElkaSoft\ELKA EventLens\Logs` and `WebView2Profile`.
- Existing data migrates on startup without overwriting an existing destination. A blocked migration keeps using the old folder and retries next launch.
- Portable builds keep `Saves`, `Logs`, and `WebView2Profile` beside the executable, unchanged.

## Upgrading

Exit EventLens from its tray menu before installing. Setup remembers a previously selected installation folder. For a clean switch from the old `Elka Software` folder, uninstall the old version first, then install this preview. User data is retained on uninstall and migrated when the new app starts. Avoid launching an older build after data migration, as it still uses the old folder names.

## Downloads

- `ELKA_EventLens_Setup_0.1.0-dev.2.exe`: standard installer.
- `ELKA_EventLens_Portable_0.1.0-dev.2.zip`: extract the complete folder and run `ELKA.EventLens.App.exe`.
- `SHA256SUMS-0.1.0-dev.2.txt`: SHA-256 checksums.

Windows 10/11 x64. .NET is bundled. Setup installs Microsoft WebView2 if needed, requiring internet access; portable users need the WebView2 Runtime installed. These are unsigned preview builds. Browser login persistence depends on the website and Windows account; AI auto-send and webpage darkening remain best-effort.

## Validation

All 68 Windows checks pass, including isolated migration, existing-destination conflicts, failed-move recovery, portable isolation, and the existing UI/browser tests. Release packages were rebuilt with bundled .NET and verified to exclude user settings, captured events, browser profiles, and activity logs. Migration fixtures are synthetic; actual third-party account sessions have not been used for testing.

See the [installation and storage convention](https://github.com/torment78/ELKA.EventLens/blob/main/docs/INSTALLATION.md) for the migration rules.
